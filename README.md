# FichasFácil

MVP de una herramienta educativa para crear fichas imprimibles de Matemáticas y Lengua para Infantil y Primaria.

## Verlo en local

```bash
python3 -m http.server 4173
```

Abre <http://localhost:4173>.

## Incluye

- Fichas de sumas, restas, multiplicaciones y divisiones.
- Problemas matemáticos y lectura comprensiva inicial.
- Selección de curso, dificultad, ejercicios, nombre y temática.
- Generación lógica de operaciones y hoja de soluciones.
- Diseño responsive y preparado para imprimir en A4.

Es una versión estática sin cuentas, pagos ni backend. La integración de IA para lecturas y problemas queda preparada como siguiente fase.
