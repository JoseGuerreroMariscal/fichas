Política de privacidad

FichasFacil está diseñada para funcionar sin cuentas y sin enviar las fichas al servidor.

1. Responsable

José Guerrero Mariscal · NIF 44354807C · Cañada Real Mestas 25, 14005 Córdoba, España.

Contacto: info@fichasfaciles.es.

2. Qué datos trata FichasFacil

  • La aplicación no crea cuentas ni mantiene una base de datos de usuarios.
  • El nombre escrito en el generador se utiliza en el navegador para preparar la ficha y el PDF; no se envía al servidor.
  • Las preferencias del generador y la última actividad se guardan únicamente en el almacenamiento local del navegador.
  • Si escribes al email de contacto, se tratarán los datos que incluyas en ese mensaje para responderte.

3. Finalidades y base jurídica

Las preferencias locales se utilizan para facilitar el uso de la aplicación. La atención de consultas se basa en la gestión de tu solicitud. No se elaboran perfiles publicitarios ni se venden datos.

4. Destinatarios y conservación

Las fichas se generan en tu dispositivo. Los proveedores técnicos de alojamiento y entrega de la web pueden tratar datos técnicos imprescindibles para prestar el servicio, como solicitudes, seguridad y disponibilidad. Los mensajes de contacto se conservarán durante el tiempo necesario para atender la consulta y cumplir obligaciones legales.

5. Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad cuando sean aplicables. Para ejercerlos, escribe a info@fichasfaciles.es, indicando el derecho que deseas ejercer y aportando información suficiente para identificar la solicitud.

También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).

6. Menores

La web no solicita directamente datos de menores. Se recomienda que madres, padres, tutores o docentes supervisen el uso de la herramienta y no introduzcan datos personales innecesarios en las fichas.
